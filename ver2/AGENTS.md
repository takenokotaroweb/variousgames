# AGENTS.md — このリポジトリで作業するAIへの指示

- GML「テレビ向けWebゲーム 開発指示書」(第1.2版以降)を必ず守ること。規則番号は指示書のもの。
- 配信されるのは `web/` の中身だけ。`web/` に説明書き・メモ・控え(.md / .bak など)・`.htaccess` を置かない [GIT-3]。
- スクリプトは外部ファイルのみ。インライン `<script>`・`onclick="…"`・`eval`・外部CDN・外部通信は禁止 [SEC-1〜4]。
- 構文は ES2019 相当まで。`?.` と `??` は使わない。CSS の `inset` プロパティ / `aspect-ratio` / `dvh` / `:focus-visible` も使わない [SEC-8]。
- 寸法は `--u`(ステージ幅の1%)で指定する。`px` は 1px の罫線だけ [LAY-2, 3]。操作部品と文字は外周5%の内側に置く [LAY-7]。
- 文言は `web/js/i18n.js` の辞書に置き、`t('キー', {値})` で引く。文をつなぎ合わせない [I18N-2, 3]。文言を変えたら `tools/make_fonts.py` で書体を作り直す。
- 戻るキーは「処理したときだけ」`preventDefault()`。タイトルでは `history.back()`(履歴が無ければ未処理で返す)[BACK-1〜3]。
- キーイベントで `stopPropagation()` を使わない [PWR-3]。`localStorage.clear()` や `gml.` で始まるキーに触らない [PWR-1]。
- CSS・JS を変えたら、`index.html` の `?v=` を上げる [DLV-4]。
- 変更後は README の「確認の手順」を実際に操作して確かめ、結果を `docs/` に残す。

## このゲーム固有の注意

- 1問は「問題番号 → 見る(45秒) → TIME UP! → 答え合わせ → 答え」の5段階(game.js の `phase`: banner / look / timeup / check / answer)。進行は0.1秒ごとの `tick()` が経過時間を見て決める(フレーム数・CSSアニメの終了イベントには頼らない [PERF-4, 5])。
- やめる確認を出している間、画面が隠れている間、一時停止中(`S.paused`)は時間を止める(`pauseClock` / `resumeClock`)。一時停止中は `resumeClock` が動かないので、確認や画面の切り替えから戻っても止まったまま。
- 見る時間は `LOOK_MS`(45秒)。リモコン操作の無い区間が60秒を超えると計測されないので、大きく延ばさないこと [PWR-4]。
- 答えの交互表示は CSS の `opacity` だけで行う(`.pic.blink img.ans`)。入れ替えの間隔を短くするときは、1秒に3回を超えないこと [CNT-9]。
- 問題の絵(-q)と答えの絵(-a)は同じ位置で切り抜くこと。ずれると交互表示で絵が揺れて見える。
- 保存はしない(記録なし)。
- BGM は2曲(`audio/bgm_a.mp3` / `bgm_b.mp3`、`BGM_FILES`)。問題の番号で交互に選ぶ(`bgmPick`)。「見る」の間だけ鳴らす(問題番号の表示中は鳴らさない)。問題の始めに消音のまま再生しておき(`bgmRestart`)、「見る」が始まったら(`startLook` → `bgmSync`)曲の頭に戻して消音を外す。音量の変更が効かない端末があるので、止める・立ち上げるは回数で必ず終わらせる。残り5秒でフェードアウトしてチクタクに替わる。鳴らす・止めるは `bgmSync()` に集め、確認・非表示・音オフでも止まること。
