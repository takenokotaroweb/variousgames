## 1. 1問の流れ

- [x] はじめる → 「第1問」(約1.8秒)→ 45秒のバーが減る(残り10秒で赤)→ 0 で「TIME UP!」が飛び出す → 「答え合わせ」のページ → 答え。実時間で通しで確認(ja / en)
- [x] BGM を2曲に差し替え。第1・3・5問は A(bgm_a.mp3)、第2・4問は B(bgm_b.mp3)、第5問のあとの第1問は A。各問で曲の頭から鳴ることを確認。読み込みは `?v=13`。ver13 で曲の音量を約5dB下げた(約 -23 LUFS)
- [x] BGM: 「第1問」の表示中は消音で再生しておき、表示が消えて絵が見えた瞬間に曲の頭(0.1秒以内)から通常の音量で鳴る。やめる確認を「第1問」の表示中に開いて戻っても、曲は頭から。残り5秒で止まってチクタクに替わる。やめる確認の間は止まり、続けると続きから再開。次の問題では曲の頭から。音をオフにすると鳴らない(Chromium の既定の自動再生の制限のまま確認)
- [x] 答えの画面で、答えの絵と問題の絵が0.8秒ごとに入れ替わる(赤い〇が点滅して見える。1秒に3回を超えない)
- [x] 一時停止: 決定で止まり、時間・BGM が止まって「一時停止中」が出る。3秒待っても残り時間は変わらない。やめる確認から戻っても止まったまま。もう一度決定で続きから(ja / en)
- [x] 時間が来ると「一時停止」が消え、フォーカスは「やめる」へ。答えでは「次の問題へ」
- [x] 問題の絵と答えの絵の位置がずれていない(入れ替えても絵が揺れない)
- [x] 「次の問題へ」で第2問。第5問のあとは「第1問へ」
- [x] 下のバー: 「第1問」・残り時間のバー・秒数の高さ(中心)がそろっている。TIME UP! で一時停止ボタンが消えても、バーの位置と長さは変わらない(ja / en、1920x1080 で実測)
- [x] 出題順: 積み木 → ピクニック → 公園 → 釣り → 花かんむり(各問の絵を画面で確認)。第5問のあとは第1問へ
- [x] やめる確認を出している間、画面が隠れている間は残り時間が減らない
