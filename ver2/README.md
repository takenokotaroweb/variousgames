# まちがいさがしゲーム(Find the Differences)

左右に並んだ2枚の絵を45秒間よく見て、違うところを5つ探す間違い探し。見ている間の操作は要らない(BGMが流れ、最後の5秒はチクタク)。時間になると「TIME UP!」、続いて「答え合わせ」のページが出て、答えの絵(赤い〇付き)と問題の絵が交互に表示され、赤い〇が点いたり消えたりして違うところが分かる。全5問。テレビのリモコン(上下左右・決定・戻る)、タッチ、マウスで操作できる。「おうちの宝さがし」と同じ仕様(GML 開発指示書 第1.2版)で作っている。

- 版: ver13(読み込みの `?v=13`)
- 変更の履歴

  - ver11: BGM の頭が切れて聞こえるのを直した(「第1問」の表示が消えて絵が見えた瞬間に、曲の頭から鳴らす。鳴らし始めは0.15秒だけ立ち上げて通常の音量にする)
  - ver10: アイコン(`icons/`)を作り直した

## 1問の流れ

| 段階 | 長さ | 画面 |
|---|---|---|
| 問題番号 | 1.8秒 | 絵を少し暗くして「第1問」と効果音(BGM はまだ鳴らさない) |
| 見る | 45秒 | 絵が見えた瞬間に BGM が曲の頭から鳴る。残り時間のバーが減っていく(残り10秒で赤色)。残り5秒で BGM を0.5秒かけてフェードアウトして止め、0.5秒ごとに「チク」「タク」 |
| TIME UP! | 2.4秒 | 絵を暗くして「TIME UP!」が飛び出し、弾んで止まる |
| 答え合わせ | 2.6秒 | 絵の場所に「答え合わせ」「正解は…」のページ(赤い輪が広がる飾り) |
| 答え | 次へ進むまで | 答えの絵と問題の絵を0.8秒ごとに入れ替える(1秒に3回を超える明滅にはしない [CNT-9]) |

- 秒数は `web/js/game.js` 冒頭の `LOOK_MS` などで変えられる(タイトルの説明文の秒数も連動する)。
- 「一時停止」: 問題番号と「見る」の間だけ出る。押すと時間・BGM・チクタクが止まり、絵の上に「一時停止中」が出る(絵はそのまま見られる)。もう一度押す(「再開」)と続きから。最初のフォーカスはこのボタンなので、リモコンの決定だけで止められる。やめる確認から戻っても止まったまま。
- 出題順: 第1問 積み木 → 第2問 ピクニック → 第3問 公園 → 第4問 釣り → 第5問 花かんむり(`game.js` の `STAGES` の並び)。
- 答えの画面の「次の問題へ」で次の問題。第5問のあとは「第1問へ」で最初に戻る。
- 記録(保存)は無い。`localStorage` は使っていない。

## 操作一覧

| 操作 | リモコン / キーボード | タッチ・マウス |
|---|---|---|
| ボタンを選ぶ | 左右(上下) | — |
| 押す | 決定(Enter) | タップ・クリック |
| 戻る | 戻る(Backspace / Escape) | 画面の「やめる」「タイトルへ」「おわる」 |

- 見ている間に選べるのは「一時停止(再開)」「音」「やめる」(最初のフォーカスは「一時停止」)。時間が来たら「一時停止」は消え、フォーカスは「やめる」へ移る(やめる確認の初期フォーカスは「続ける」)。
- 押しっぱなし対策: 決定・戻るは300ms以内の連続を1回とみなす。方向キーは自前のリピート(初回350ms、以後110ms)。

## 画面遷移と戻るの動作

```
読み込み中 → タイトル ─はじめる→ 第1問(問題番号 → 見る → TIME UP! → 答え合わせ → 答え) ─次の問題へ→ 第2問 … 第5問 ─第1問へ→ 第1問
              └ おわる → ランチャー         │                         └ タイトルへ → タイトル
                                           └ やめる → 確認 → タイトルへ
```

| 画面 | 戻るを押したとき | `preventDefault` |
|---|---|---|
| タイトル | 履歴があれば `history.back()`、無ければ何もしない | 履歴あり=する / なし=しない |
| 問題番号・見る・TIME UP!・答え合わせ | 「やめてタイトルにもどりますか？」(初期フォーカスは「続ける」。確認中は時間を止める) | する |
| やめる確認 | 閉じて続きへ | する |
| 答え | タイトルへ | する |
| 読み込み中 | タイトルと同じ | 同上 |

画面が隠れたとき(`visibilitychange`)も時間と音を止める。BGM は、やめる確認の間・画面が隠れている間・音をオフにしたときも止まる。

## パワータンクについて [PWR-4]

見ている45秒(+演出約7秒)はキー操作が無いが、答えを見て「次の問題へ」を押すまでを含めても60秒前後に収まるように見る時間を決めた。一時停止して長く見ている間は、60秒を超えた分が計測されない(ゲームの進行には影響しない)。答えの画面で「次の問題へ」を押すと次の問題に進む(自動では進まない)。

## 問題の追加・差し替え

- 元の画像(2500×1294、左右の絵が並んだもの)の「問題」と「答え(赤い〇付き)」を、白い余白を少し残して切り抜き、横1920に縮小して `web/img/stages/<問題名>-q.jpg` / `-a.jpg` に置く(2枚は必ず同じ位置で切り抜く。ずれると交互表示で絵が揺れる)。
- `web/js/game.js` の `STAGES` に問題名(ファイル名)を足す。画面には「第5問」のように番号だけが出る。

## BGM

- BGM は2曲を問題ごとに交互に流す。第1・3・5問は `web/audio/bgm_a.mp3`(ミュゼット・ワルツ、約77秒)、第2・4問は `web/audio/bgm_b.mp3`(カフェ・スウィング、約64秒)。どちらも本ゲーム用に Claude が作曲した曲で、`web/` 全体を5MB以内に収めるため 96kbps に変換してある。さらに BGM を控えめにするため、音量を約5dB下げてある(端末によって `BGM_VOL` が効かないことがあるので、ファイル自体を小さくしている)。この2曲は別に生成したデータを取り込んだもので、作るためのスクリプトは `tools/` にない。
- 曲を替えるときは、同じ名前の mp3 で置き換え、`game.js` の `BGM_FILES` の `?v=` の番号を上げる(端末に古い曲が残らないように)。曲を増やすときは `BGM_FILES` に足すと、問題の番号順に順番に使われる。
- `tools/make_bgm.py` は ver11 まで使っていた曲(カフェ・低め・まろやか)を作る道具で、今の2曲とは関係しない(今の2曲の作成スクリプトは無い)。1問ごとに曲の頭から流れ、残り5秒で止まる(やめる確認から戻ったときは続きから)。音量は `game.js` の `BGM_VOL`。鳴らし始めは `BGM_FADEIN_MS`(0.15秒)だけ立ち上げて、プチッという音を防ぐ。
- ボタンを押した直後でないと音を出せない端末に備え、問題の始め(ボタンを押した直後)に消音(ミュート)のまま再生を始めておき、絵が見えたところで曲の頭に戻して消音を外している。音量の変更が効かない端末もあるため、音量0ではなく消音を使う。
- 差し替えた曲は `web/licenses.txt` に作成方法と権利を書き足すこと [CNT-7]。

## 書体とタイトル画像

- 書体は Zen Maru Gothic(SIL OFL 1.1)を `web/fonts/` に同梱している。ゲームで使う文字だけに絞ったサブセット(Medium=500 / Bold=700)。
- **辞書(`web/js/i18n.js`)の文言を変えたら、サブセットを作り直すこと。** `pip install fonttools` のうえで `python tools/make_fonts.py <ZenMaruGothic の ttf があるフォルダ>`。
- タイトル画像 `web/img/ui/title-ja.svg` / `title-en.svg` は Zen Maru Gothic Black の文字を図形にしたもの。作り直しは `python tools/make_title_svg.py <ZenMaruGothic-Black.ttf> "<文字>" <出力.svg>`。
- `tools/` は配信しない(`web/` の外)。
