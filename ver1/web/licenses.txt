おうちの宝さがし / Treasure Hunt at Home — 素材とライブラリの一覧
====================================================================

■ ライブラリ
  なし(外部ライブラリ・ゲームエンジンは使っていません)

■ 書体
  Zen Maru Gothic(Medium / Bold)Version 1.001
    ファイル: fonts/zenmaru-500.woff, fonts/zenmaru-700.woff
    (ゲームで使う文字だけに絞ったサブセット。著作権表示とライセンス情報は書体の中にも残しています)
    著作権: Copyright 2021 The Zen Maru Gothic Project Authors
    ライセンス: SIL Open Font License, Version 1.1(全文はこのファイルの末尾)
    入手元: Google Fonts(https://fonts.google.com/specimen/Zen+Maru+Gothic)
            元のプロジェクト: https://github.com/googlefonts/zen-marugothic
  予備の書体: 端末の標準書体("Noto Sans JP", "Noto Sans", "Hiragino Sans", "Yu Gothic", "Meiryo", sans-serif)

■ 画像
  img/rooms/bathroom.jpg, kitchen.jpg, bedroom.jpg, living.jpg, living-shade.jpg(部屋の絵 5枚。living-shade はリビングのシェードを下ろした絵)
    作成方法: 生成AI(Adobe Photoshop の生成AI機能〈Adobe Firefly〉で生成し、自分で調整)
    生成AIのサービス名: Adobe Photoshop(Adobe Firefly)
    商用利用・再配布: 可

  img/ui/house.svg(家の絵)、img/ui/chest.svg(宝箱)
  img/items/flashlight.svg, stool.svg, cloth.svg, key.svg, bulb.svg(道具。key.svg は宝物の鍵の絵を流用)
  img/treasures/*.svg(宝物 15個)
  img/ui/owner-emblem-ja.svg(隠しメッセージ発見のエンブレム。日本語の文字入り)、owner-medal.svg(同じエンブレムから文字部分を外したもの。日本語以外で使用)
    作成方法: 素材サイトの素材を自分で加工
    入手元: Adobe Stock(https://stock.adobe.com/jp)
    ライセンス: Adobe Stock 標準ライセンス
    使用形態: 限定された視聴者に配信するテレビ向けゲームに組み込んで使用。視聴者が素材を独立したファイルとして取り出せない仕組み
    商用利用・再配布: 可

  img/ui/sparkle.svg, sound-on.svg, sound-off.svg, bulb.svg, clock.svg
    作成方法: 本ゲーム用に作成(開発時に AI〈Anthropic 社の Claude〉が SVG で作図)
    商用利用・再配布: 可

  img/ui/title-ja.svg, title-en.svg(タイトルの文字)
    作成方法: Zen Maru Gothic Black(SIL OFL 1.1)の文字の形を図形(アウトライン)にしたもの。書体のデータは含まない
    商用利用・再配布: 可

■ 音
  audio/bgm.mp3(BGM。カフェ風の落ち着いた4拍子の曲、約3分40秒をくり返し。遊んでいる間だけ控えめな音量で流す)
    作成方法: 本ゲーム用に作曲・作成(開発時に AI〈Anthropic 社の Claude〉が作曲し、tools/make_bgm_cafe.py で音を合成。外部の音源・既存の曲は使っていない)
    商用利用・再配布: 可
  効果音: 音声ファイルなし(ブラウザの Web Audio API で、その場で合成しています)
