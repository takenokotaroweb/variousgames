# おうちの宝さがし(Treasure Hunt at Home)

家の4部屋(寝室・洗面所・キッチン・リビング)を巡って道具と色付きの数字を集め、キッチンに隠れた宝箱を開ける探索ゲーム。テレビのリモコン(上下左右・決定・戻る)、タッチ、マウスで遊べる。

- 版: ver55(読み込みの `?v=55`)
- 対応言語: 日本語(ja)、英語(en)。`?lang=ja` / `?lang=en`、指定が無ければ端末の言語、対応外は英語
- 入口: `web/index.html`(1ページで完結。外部通信なし、ビルドなし)

## 操作一覧

| 操作 | リモコン / キーボード | タッチ・マウス |
|---|---|---|
| 選ぶ | 上下左右 | — |
| 調べる・押す | 決定(Enter) | タップ・クリック |
| 隣の部屋へ | 部屋の左端・右端でさらに左右(左右キーでは届かない場所は飛ばす) | 画面左右の ◀ ▶、下の部屋ボタン |
| 下のバーへ / 部屋へ戻る | 部屋の一番下で下 / バーで上 | — |
| 戻る | 戻る(Backspace / Escape) | 画面の「やめる」「閉じる」「おわる」 |
| ダイヤルの数字 | 画面のテンキー(数字キーは近道) | テンキーをタップ |

音: BGM(`web/audio/bgm.mp3`、カフェ風の曲)は部屋で遊んでいる間だけ、控えめにくり返し流す。「はじめる」のあと、はじめの案内を閉じたとき(OK・戻る)、ポップアップが消えてから0.5秒後に曲の頭から鳴らす。クリアでは曲をすっと小さくしてファンファーレを鳴らし、約1秒おいてから少し小さめの音量(約 -4dB)でゆっくり戻す。タイトルでは鳴らない。音オフ・画面が隠れたときは止め、戻ると続きから。端末によって音量の指定が効かないため、曲のファイル自体を小さく(約 -28 LUFS)作ってある。効果音は Web Audio でその場で合成。

押しっぱなし対策: 決定・戻るは300ms以内の連続を1回とみなす。方向キーは自前のリピート(初回350ms、以後110ms、合図が500ms途切れたら停止)。

## 画面遷移と戻るの動作

```
読み込み中 → タイトル ─はじめる→ プレイ ─宝箱が開く→ クリア
              │                    │                  ├ もう一度遊ぶ → プレイ
              ├ 記録をリセット → 確認  ├ やめる → 確認    └ タイトルへ → タイトル
              └ おわる → ランチャー    └ (各種メッセージ / 宝箱のダイヤル)
```

| 画面 | 戻るを押したとき | `preventDefault` |
|---|---|---|
| タイトル | 履歴があれば `history.back()`、無ければ何もしない | 履歴あり=する / なし=しない |
| プレイ中(ダイアログなし) | 「ゲームをやめますか？」(初期フォーカスは「続ける」) | する |
| やめる確認 | 閉じてプレイへ(=続ける) | する |
| メッセージ | 閉じる(=キャンセル。宝箱発見のメッセージなら、ダイヤルは開かない) | する |
| 宝箱のダイヤル | 閉じる(数字を消すのは画面の「消す」) | する |
| 記録リセットの確認 | 閉じる(=やめる) | する |
| クリア | タイトルへ | する |
| 読み込み中 | タイトルと同じ | 同上 |

## 保存キー

| キー | 内容 | 検証 |
|---|---|---|
| `vendor.takara2.zukan.v1` | 手に入れた宝物の一覧(JSON配列、`"0-0"`〜`"4-2"`) | 配列でなければ破棄、要素は `/^[0-4]-[0-2]$/` のみ採用 |
| `vendor.takara2.best.v1` | ベストタイム(ミリ秒) | 正の有限数かつ100時間未満のみ採用 |

- 頭の `vendor.takara2` は仮の値。`web/js/game.js` 冒頭の `SAVE_PREFIX` を、GMLと決めた「識別名.ゲームID」に差し替える(公開前のため旧キーからの移行はしない)。
- タイトルの「記録をリセット」は、この2つのキーだけを個別に消す(`localStorage.clear()` は使わない)。

## 寄り道(クリアには不要)

リビングの「スタンドライト」で電球切れに気づく → 寝室の右のテーブルランプ(ラベルなし。選んだときだけ〇が見える隠し場所。気づく前は反応しない)で電球を借りる(もう一度調べると戻す。借りる・戻すを交互に切り替え) → リビングの「スタンドライト」に入れて点灯させ、さらに「窓辺」でシェードを下ろして部屋を暗くすると(順番はどちらが先でもよい)、家主の隠しメッセージが壁に映し出される(記録には残さず、図鑑にも出さない)。窓辺は調べるたびにシェードを下ろす・上げるを切り替える(下ろすとリビングの絵が `living-shade.jpg` に切り替わり、部屋が暗くなる)。シェードを下ろしていてスタンドライトが点いていない間は、リビングの星2つが見えなくなり(選べない)、本棚と額縁は「暗くてよく見えない。」になる。ライトを点ければ、シェードを下ろしたままでも普段どおり調べられる。壁のメッセージの「電気を消す」でライトを消せる。シェードが上がっているときにスタンドライトを選んで出る「あたたかい光がともっている」の画面にも「電気を消す」が出る。電球は入ったままなので、スタンドライトを選ぶと点け直せる。ヒントでは教えない。メッセージが自動で映るのは最初の1回だけ。その後は、点灯中かつシェードを下ろしているときにスタンドライトを調べると、「壁に、文字が映っている…。」のひと言のあとにもう一度見られる(消したライトをシェードを下ろしたまま点け直したときも同じ)。メッセージを見たプレイでは、クリア画面の宝物図鑑の下に「家主の隠しメッセージを見つけた！」の印が出る(記録には残さない)。

## 書体とタイトル画像

- 書体は Zen Maru Gothic(SIL OFL 1.1)を `web/fonts/` に同梱している。ゲームで使う文字だけに絞ったサブセット(Medium=500 / Bold=700)。
- **辞書(`web/js/i18n.js`)の文言を変えたら、サブセットを作り直すこと。** 入っていない文字は予備の書体で表示される。
  `pip install fonttools brotli` のうえで `python tools/make_fonts.py <ZenMaruGothic の ttf があるフォルダ>`。brotli があれば woff2 を作る(その場合は style.css の `url(…woff)` と `format("woff")` を woff2 に書き換える)。
- タイトル画像 `web/img/ui/title-ja.svg` / `title-en.svg` は Zen Maru Gothic Black の文字を図形にしたもの。作り直しは `python tools/make_title_svg.py <ZenMaruGothic-Black.ttf> "<文字>" <出力.svg>`。
- `tools/` は配信しない(`web/` の外)。
