# AGENTS.md — このリポジトリで作業するAIへの指示

- GML「テレビ向けWebゲーム 開発指示書」(第1.2版以降)を必ず守ること。規則番号は指示書のもの。
- 配信されるのは `web/` の中身だけ。`web/` に説明書き・メモ・控え(.md / .bak など)・`.htaccess` を置かない [GIT-3]。
- スクリプトは外部ファイルのみ。インライン `<script>`・`onclick="…"`・`eval`・外部CDN・外部通信は禁止 [SEC-1〜4]。
- 構文は ES2019 相当まで。`?.` と `??` は使わない。CSS の `inset` / `aspect-ratio` / `dvh` / `:focus-visible` も使わない [SEC-8]。
- 寸法は `--u`(ステージ幅の1%)で指定する。`px` は 1px の罫線だけ [LAY-2, 3]。操作部品は外周5%の内側に置く [LAY-7]。
- 文言は `web/js/i18n.js` の辞書に置き、`t('キー', {値})` で引く。文をつなぎ合わせない [I18N-2, 3]。
- 戻るキーは「処理したときだけ」`preventDefault()`。タイトルでは `history.back()`(履歴が無ければ未処理で返す)[BACK-1〜3]。
- キーイベントで `stopPropagation()` を使わない [PWR-3]。`localStorage.clear()` や `gml.` で始まるキーに触らない [PWR-1]。
- 保存キーは `SAVE_PREFIX`(game.js 冒頭)から作る。読み込んだ値は必ず検証する [SAVE-1〜3]。
- CSS・JS を変えたら、`index.html` の `?v=` を上げる [DLV-4]。
- 変更後は README の「確認の手順」を実際に操作して確かめ、結果を `docs/` に残す。

## このゲーム固有の注意

- 部屋の並び(◀▶・左右キーで回る順)は 寝室 → 洗面所 → キッチン → リビング。始まりはリビング。
- 左右キーでは選べず上下キーでだけ選べる場所(見つけにくくするため): 洗面所の戸棚・洗濯かご、キッチンの上の棚、寝室の左の絵の星・椅子の星、リビングの窓辺・カーペットの星(game.js の `VERTICAL_ONLY`)。
- 個別に決めた移動先: 洗面所の蛇口で下 → 戸棚、キッチンのコンロで上 → 上の棚(game.js の `NAV_OVERRIDE`)。
- 部屋ごとの最初のフォーカス: リビング=額縁、キッチン=コンロ、寝室=枕、洗面所=鏡。
- 宝箱(キッチンのパントリー)は、手がかりが1つも無いときはダイヤルを開かない。
- スタンドライトの「電球が切れている」は、寄り道の伏線。寝室のテーブルランプ(電球切れに気づいた後だけ現れる、ラベルなしの隠し場所)の電球を入れ、窓辺のシェードを下ろして部屋を暗くすると家主のメッセージが壁に映る(クリアには不要・ヒントでも教えない)。
