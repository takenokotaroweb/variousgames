# 宇宙パトロール(Space Patrol)

テレビのリモコンだけで遊べる、インベーダー型のシューティング。左右に動きながら少しずつ下りてくる宇宙人の群れを、自分の船から出る光線で星に変える。群れを全部星に変えると次の波へ。宇宙人の弾に当たると船が1つ減り、船が無くなるか宇宙人が地上に着くとゲームオーバー。テレビのリモコン(上下左右・決定・戻る)、タッチ、マウスで操作できる。「おうちの宝さがし」「まちがいさがしゲーム」と同じ仕様(GML 開発指示書 第1.2版)で作っている。

- 版: ver23(読み込みの `?v=23`。変えたのは game.js と index.html の読み込み番号)
- 変更の履歴

  - ver22: 彗星を見送っても点は入らないようにした。彗星の出る割合を 10回に3回から 2回に1回に増やした。タイトルの得点表の彗星の絵を一回り小さくし、文言を「彗星は撃たずに見送ろう」(英語 Let comets pass!)にした。波をクリアして次の波に進むと、自分の船を必ずまん中に戻すようにした
  - ver21: 上を横切るものに「彗星」を加えた(10回に3回くらい)。彗星は撃ってはいけない: 撃たずに見送ると 100点、撃つと割れてかけらが3つ降ってきて、船に当たると船が1つ減る(レンガの壁で止まる)。彗星が出ている間は、上の表示に「彗星だ！ 撃たないで！」を出す。円盤の点数を、ランダム(50 / 100 / 150 / 300)から 200点に決めた(既存のインベーダーゲームと同じ点数だったため)。タイトルの得点表に彗星を加えた。文言が増えたので書体を作り直した

  - ver07: 画面をタップ・クリックしても船が動かないようにした(撃つだけ)。船を動かすのは、リモコン・キーボードの左右キーと、タッチで操作したときに出る ◀ ▶ ボタンだけ。PC で画面をクリックしたときや、iPad でボタンを少し外して押したときに、船が勝手に動いて見えたため
  - ver06: キーを離した合図(keyup)が届かない端末で、1回押すだけで船が0.9秒動き続け、勝手に進んだり戻ったりして見えたのを直した。宇宙人の弾に当たったあと、船を真ん中に戻さず、その場から再開するようにした

| 円盤型の宇宙船 | 20〜30秒ごとに上を横切る(ver14 で描き直し)。当てると 200点(ver21) |
| 彗星 | 円盤とは別に 20〜30秒ごとに上を横切る(ver21 で追加、ver23 で円盤と別の時計にした)。撃ってはいけない(見送っても点は入らない)。撃つと割れて、かけらが3つ降ってくる(船に当たると船が1つ減る。レンガの壁で止まる)。出ている間は上の表示に「彗星だ！ 撃たないで！」 |
| バリア | レンガの壁が4つ(ver20)。光線が当たるとレンガにひびが入り、もう1回で崩れる。宇宙人の弾は1回で崩す。波ごとに元に戻る |
| 波 | 全部星にすると「第◯波 クリア！」→ 次の波。波が進むと群れが少し下から始まり、少し速くなる |
| 船 | 「ゆっくり」は5、「ふつう」「はやい」は3。弾に当たると1.6秒後にその場から再開する |
| 光線 | 画面に出せるのはふだん2本まで。「自動で撃つ」がオンのときは、自分で押した分を足して4本まで(自動の2本が飛んでいても、押せば必ず出る) |
| ゲームオーバー | 船が無くなる、または宇宙人が地上(線)の近くまで下りてくる |

### タイトルの設定(「◀ 値 ▶」の部品 [UI-2]。変えるとすぐ保存)

| 設定 | 値 | 内容 |
|---|---|---|
| 速さ | ゆっくり / ふつう / はやい | 群れの動く速さ、宇宙人の撃つ回数・弾の速さ、船の数が変わる(`game.js` の `LEVELS`) |
| 自動で撃つ | オフ / オン | オンにすると約0.5秒ごとに自動で光線が出る(左右に動くだけで遊べる)。オンのときも、自分で押せば光線が追加で出る |
| BGM | オン / オフ | BGM。遊んでいる途中は一時停止のメニュー、または下キーでも切り替えられる |
| 効果音 | オン / オフ | 光線・星に変わる音など。遊んでいる途中は一時停止のメニューでも切り替えられる |

画面右上の音のボタン(タッチ・マウス用)は、音楽と効果音をまとめてオン・オフする。

最高得点は速さごとに記録し、タイトルに「最高得点(ふつう): 1,230」のように出す。

## 操作一覧

| 操作 | リモコン / キーボード | タッチ・マウス |
|---|---|---|
| 船を左右に動かす | 左右(押しっぱなしで動き続ける) | 下の ◀ ▶ ボタン(画面をタップ・クリックしても船は動かない) |
| 光線を撃つ | 決定、または上(押しっぱなしで連射) | 画面をタップ・クリック(1発)／下の「撃つ」ボタン |
| BGM のオン・オフ | 下(遊んでいる途中。押しっぱなしでも1回だけ切り替わる) | 一時停止のメニューの「BGM」 |
| 一時停止 | 戻る(Backspace / Escape) | 右上の「一時停止」 |
| メニューのボタンを選ぶ | 上下左右 | — |
| メニューのボタンを押す | 決定(Enter) | タップ・クリック |

- タッチ用のボタン(◀ ▶ 撃つ)は、タッチ・マウスで操作したときだけ下に出る。リモコンのキーを押すと隠れる [TOUCH-6]。
- 押しっぱなし対策 [IN-5, IN-6]: 決定・戻るは300ms以内の連続を1回とみなす。メニューの方向キーは自前のリピート(初回350ms、以後110ms)。遊んでいる間の移動と連射は、続けて押していても20秒で止まる。
  - keyup(キーを離した合図)が届く端末(PC など): keyup で止まる。keyup を取りこぼしたときは、合図が0.9秒途切れたら止まる。
  - keyup が届かない端末: 1回押すと0.15秒だけ動く。押しっぱなしの合図(続けて届く keydown)が続く間だけ動き続け、0.25秒途切れたら止まる。押しっぱなしの合図が届くまでの間(約0.5秒)は止まって待つ。
  - 端末から keyup が1回でも届いたら、それ以後は「keyup が届く端末」として扱う(タイトルで決定を押した時点でたいてい分かる)。
- 決定の長押し(3秒以上)が必要な操作は無い [IN-7]。

## 画面遷移と戻るの動作

```
読み込み中 → タイトル ─はじめる→ 第1波の札 → 遊ぶ ─全部星に→ クリア → 第2波の札 → 遊ぶ …
              └ おわる → ランチャー      │                        └ 船が無くなる／着地 → ゲームオーバー ─もう一度→ 第1波
                                         └ 戻る → 一時停止 ─続ける→ 遊ぶ                         └ タイトルへ → タイトル
                                                     ├ 最初から → 第1波
                                                     └ タイトルへ → タイトル
```

| 画面 | 戻るを押したとき | `preventDefault` |
|---|---|---|
| タイトル | 履歴があれば `history.back()`、無ければ何もしない | 履歴あり=する / なし=しない |
| 第◯波の札・遊ぶ・クリア | 一時停止のメニューを出す(初期フォーカスは「続ける」[BACK-9]) | する |
| 一時停止のメニュー | 閉じて続きから | する |
| ゲームオーバー | タイトルへ | する |
| 読み込み中 | タイトルと同じ | 同上 |

画面が隠れたとき(`visibilitychange`)は一時停止のメニューを出して止め、音も止める [PERF-6]。

## 保存キー [SAVE-1]

| キー | 内容 |
|---|---|
| `vendor.spacepatrol.settings.v1` | `{"v":1,"level":"normal","auto":false,"sound":true,"music":true}`(速さ・自動で撃つ・効果音・音楽。`music` は ver02 で追加し、無ければオンとして読む) |
| `vendor.spacepatrol.best.v1` | `{"v":1,"slow":0,"normal":0,"fast":0}`(速さごとの最高得点) |

- 読み込んだ値は型・範囲・許可リストで確かめてから使う。壊れていたら初期値で起動する [SAVE-2, 3]。
- 頭の `vendor.spacepatrol` は、GML と決めた識別名・ゲームIDに差し替える(`web/js/game.js` 冒頭の `SAVE_PREFIX`)。

## パワータンクについて [PWR-4]

ゲームの進行(船を動かす・撃つ)はすべて利用者のキー操作による。波の札(1.8秒)・クリア(2.2秒)だけは操作なしで進むが、短いので60秒を超える無操作区間は生まれない。「自動で撃つ」をオンにしても、船を動かすのは利用者の操作。

## キャラクターの原画

- `art/characters/*.svg` がキャラクターの原画(ver16、輪のある星の子と円盤型の宇宙船は ver17 で差し替え、彗星 `comet.svg` は ver21 で Claude が作図)。開発時に AI〈Anthropic 社の Claude〉が作図したドット絵を、制作者が Adobe Illustrator で手直ししたもの。10 単位 = 1マス。
  - ringed-planet(輪のある星の子・30点)、crystal(目のある結晶・20点)、satellite-robot(人工衛星ロボ・10点)、rocket(自分の船)、saucer(円盤型の宇宙船)、star(宇宙人が変わる星)。`-1` / `-2` は交互に切り替わる2コマ。
- ゲームは画像ファイルを読まず、`web/js/game.js` の `SPR`(文字の並び。1文字 = 半マス、`X` 色・`W` 白)から描く。原画を直したら `python tools/svg_to_rows.py art/characters` で並びを出し、`SPR` に貼り替える。色は `COL`。
- 星(`star.svg`、ver18)は斜めの四角があるのでマス目に直せない。`svg_to_rows.py` が多角形の頂点の並びを出すので、game.js の `STAR_SHAPE` に貼り替える。
- `art/` は配信しない(`web/` の外)。

## 書体とタイトル画像

- 書体は Zen Maru Gothic(SIL OFL 1.1)を `web/fonts/` に同梱している。ゲームで使う文字だけに絞ったサブセット(Medium=500 / Bold=700、各約51KB)。
- **辞書(`web/js/i18n.js`)の文言を変えたら、サブセットを作り直すこと。** `pip install fonttools` のうえで `python tools/make_fonts.py <ZenMaruGothic の ttf があるフォルダ>`。
- タイトル画像 `web/img/ui/title-ja.svg` / `title-en.svg` は Zen Maru Gothic Black の文字を図形にしたもの(色 #FFD43B)。作り直しは `python tools/make_title_svg.py <ZenMaruGothic-Black.ttf> "<文字>" <出力.svg>`。
- `tools/` は配信しない(`web/` の外)。

## ゲームオーバーのジングル

- `web/audio/gameover.mp3`(2秒)。2秒の長さで作曲した曲で、BGM と同じイ短調・ピコピコした音色。120BPM の4拍で、1拍目に「ミ・ド・ラ」、2拍目に「レ・シ・ソ♯」と和音を駆け下り、3〜4拍目に低い「ラ」の和音を音程を変えずにのばして、自然に消えて終わる。和音の頭に「電源が切れていく」ような下がる音を短く重ねている。本ゲーム用に作曲したもので、`python tools/make_jingle.py web/audio` で作り直せる(numpy と ffmpeg が必要)。
- 船が無くなったときと、宇宙人が地上に着いたときの両方で鳴る。BGM が小さくなり始めてから0.3秒後に鳴らし始め、そのあと「ゲームオーバー」の画面が出る。
- 効果音か BGM のどちらかがオンなら鳴る。両方オフのときだけ鳴らない。
- 「もう一度」「最初から」を押したとき・画面が隠れたときは止める。
- 操作の直後でないと音を出せない端末のために、「はじめる」などを押したときに一度だけ、消音のまま鳴らしてすぐ止めておく。鳴らせなかったときは、短い効果音を代わりに鳴らす。
- 音量は BGM と同じ。曲そのものの大きさを BGM と同じ約 -20 LUFS にそろえ、ゲームの中で鳴らす音量も `JINGLE_VOL = BGM_VOL`(0.35)にしてある。BGM の音量を変えると、ジングルも一緒に変わる。

## BGM

- `web/audio/bgm.mp3`(約55秒、くり返し。イ短調・140BPM・32小節のピコピコしたテクノポップ調。矩形波の旋律、オクターブで跳ねるベース、16分音符のアルペジオ、電子ドラム)。本ゲーム用に作曲したもので、作り方は `tools/make_bgm.py` の先頭に書いてある。`python tools/make_bgm.py web/audio` で作り直せる(numpy と ffmpeg が必要)。
- 鳴るのは遊んでいる間(第◯波の札・遊ぶ・当たった直後・クリア)だけ。一時停止・画面が隠れたとき・タイトルでは止まり、ゲームオーバーでは約0.5秒で小さくして止まる。一時停止から戻ると続きから、新しいゲーム(はじめる・もう一度・最初から)は曲の頭から。
- 鳴らし始めは、利用者の操作(決定・タップ)の中で行う(操作の直後でないと音を出せない端末があるため)。
- BGM が鳴っている間は、宇宙人の群れの足音(4音のくり返し)を鳴らさない(曲とぶつかるため)。音楽をオフにすると足音が戻る。
- 別の曲(Suno で作った曲など)に替えるときは、同じ名前の mp3 で置き換え、`game.js` の `audio/bgm.mp3?v=` の番号を上げる(端末に古い曲が残らないように)。音量は `game.js` の `BGM_VOL`。差し替えた曲は `web/licenses.txt` に作成方法と権利を書き足すこと [CNT-7]。
- くり返しのつなぎ目: mp3 の性質上、端末によっては曲の頭に戻るときにごく短い切れ目が入ることがある(約55秒に1回)。

## 調整できる値(`web/js/game.js` 冒頭)

| 値 | 意味 |
|---|---|
| `LEVELS` | 速さごとの、群れの速さ・撃つ回数・弾の速さ・船の数 |
| `READY_MS` / `CLEAR_MS` / `HIT_MS` | 札・クリア・当たった後の待ち時間 |
| `FIRE_EVERY_MS` / `AUTO_FIRE_MS` | 押しっぱなし・自動で撃つときの間隔 |
| `PLAYER_SPEED` | 船の動く速さ |
| `BGM_VOL` | BGM の音量(0〜1) |
